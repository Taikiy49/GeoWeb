# Geolabs website behavior

This public marketing website serves prospective clients and applicants. Source authority is the user request and Wix saved New/Newer content documented in `docs/MIGRATION.md`. No local accounts, uploads, payments, publishing controls, or destructive operations exist.

- All routes share the shell, original Geolabs branding, design tokens, and responsive behavior. Route changes reset scroll and focus the main landmark; anchor destinations account for the sticky header.
- Navigation collapses at 1150px. Menu links enter briefly from the left; reduced motion removes this entrance. Its button exposes expanded state. Escape closes it and restores focus; following a route closes it. The list is nonmodal and remains keyboard accessible.
- Homepage background video uses the original Geolabs cover footage. It autoplays muted and loops inline when motion is permitted. Reduced-motion preference suppresses autoplay; changing that preference pauses playback. A named native button pauses/resumes playback. The poster is a real frame from the clip, with no separate full-video link.
- The portfolio renders the complete small local collection. Search and market filters combine and persist in URL parameters; browser Back restores the query. No results offers a clear-filters button; the search clear action restores input focus.
- Project/service cards lead to individual pages. Breadcrumbs link to owning collections. Verified legacy Wix aliases redirect to canonical pages before route matching; old homepage fragments and profile anchors remain compatible. Unknown routes show the site 404 and a working home link.
- Leadership credentials remain available in full selected profiles. Services retains complete Design/Construction Support approach text; Home links into the detailed disciplines through compact work-role introductions. Draft collections and pages display Under construction notices and noindex metadata; raw unverified narratives remain only in the repository archive. Drafts are publicly accessible, not authenticated previews.
- Careers opportunities link to careers.geolabs.net and application actions to /apply on that host. No resume-by-email application action exists. Contact uses actual phone/email links, a separate Google map beside each office’s details, and permanent directions links. The same office/map pairs stack vertically on phones; there is no separate map selector. Phone display uses `(808)841-5064`; tel links contain international digits. The original Wix submission backend is not migrated; no form success is simulated.
- Company content and images are served locally. Google supplies the lazy-loaded map iframe; its loading/error messages and permanent directions link are explicit. No server mutation or offline synchronization is implied. Images reserve card/hero geometry; below-fold images load lazily. Visible focus, semantic controls, image alternatives, reduced motion, and 320px reflow are required.

- Featured projects use a manual filmstrip with named, pressed-state thumbnail buttons and previous/next controls. Arrow keys, Home, and End navigate thumbnails. Selection resets playback. The HDOT walkway video plays only after an explicit click, uses native controls, and provides a retry state on failure. Horizontal thumbnail scrolling does not move the document.
- Preserve all five authored Home (New) film slides, including Halawa View Apartments and Ka Haku Timeshare, within the seven-frame filmstrip. Counts derive from the dataset. Preserve photo/video credits. Image-only features have no speculative location or case-study destination; their source records are in `docs/wix-home-film-source.json`.
- Entry reveals run once per route render; search updates reveal result cards only and honor live reduced-motion changes. No content depends on animation to become readable.

- ContactInquiry owns required-field and email-format feedback. Blank or whitespace-only required fields cannot prepare a draft. Inline errors are associated with their fields, invalid submission focuses the first correction, and correction preserves all entered values. Valid preparation focuses the ready draft action; editing any field removes the stale draft. Preparing a draft never opens an email app or sends a message automatically. Direct delivery remains the integration gap documented in docs/PRODUCTION-READINESS.md.

## Storytelling paths

- Home’s “Follow our story” hero action targets `#our-roots`. The story index links to roots, the International Market Place story, work roles, people and the closing contact invitation. Destinations use the shared hash focus and sticky-header behavior; the original video controls, statistic counters and seven-frame filmstrip remain available.
- Projects places the completed International Market Place narrative before regional concepts and the catalogue. “Browse all projects” targets `#project-catalogue`. The source’s 1960s–1970s account describes the place before redevelopment; August 2016 is its completion date, not an asserted start or duration of Geolabs’ engagement.
- Regional stories default to Waikīkī. Selecting Ko Olina writes `region=ko-olina`; returning to Waikīkī removes that parameter while preserving search, category and view parameters. Draft chronology notices remain visible and associated with the milestone lists. Concept dates and roles do not become verified facts through selection.
- Completed project pages expose Project context, Read the story and Continue the story anchor links. All 102 source paragraphs remain intact; the three selected longer accounts receive editorial reading subheads. The Honolulu Rail account remains explicitly conceptual/preliminary with initial plans dated 2008.
- The project continuation chooses another completed story from the supplied collection, preferring the same exact location, then market, then the remaining collection. It never represents the order as chronology. Only an unqualified source completion field can appear as completion metadata. The original catalogue query, category, view and return anchor carry through continuation links; a story opened from the Projects place/regional feature returns to that feature.
- About’s selected full-content topic offers previous/next links; its final topic continues into project stories. People closes with a project-story link. These are ordinary links and retain browser history, visible keyboard focus and the shared reduced-motion behavior.
